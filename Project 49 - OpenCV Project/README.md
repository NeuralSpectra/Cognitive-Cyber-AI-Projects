# **Project 49: OpenCV Project**

This project is an **advanced OpenCV-based computer vision implementation** focused on **image and video analysis using mathematical transformations, geometric calculations, and object detection techniques**.

**It goes beyond basic OpenCV usage by applying complex mathematical logic to accurately target, track, and analyze specific regions within images and video streams.**
---

## **Datasets & Resources Used**

This project works with **multiple data formats**, including:

* **Haar Cascade XML files** (`.xml`) for object detection
* **Video streams** (`.mp4`) for motion and frame-based analysis
* **Image files** (`.jpg`, `.png`) for static detection and processing

Each dataset type is used intentionally to demonstrate how OpenCV behaves across different visual inputs.
