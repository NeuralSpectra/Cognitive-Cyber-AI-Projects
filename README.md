## ⚠️ Important

**Large files in this repository (e.g., videos, databases) cannot be downloaded directly using the GitHub “Download ZIP” option. Doing so will result in corrupted placeholder files (often just a few bytes). To download the full content correctly, you must use Git LFS:**

**1: git lfs install**

**2: git clone https://github.com/NeuralSpectra/Cognitive-Cyber-AI-Projects.git**

**3: cd Cognitive-Cyber-AI-Projects**

**4: git lfs pull**

**Following these commands will ensure all large files are downloaded correctly and are fully usable.**
