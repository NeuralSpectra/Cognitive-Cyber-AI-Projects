# **Project 42: Stock Price Predictor**

This project focuses on **predicting Apple stock prices** using **historical market data stored in a database**.
Unlike earlier projects, **traditional machine learning models were not used**.

Instead, this project applies **deep learning and time-series modeling techniques** to capture long-term dependencies and temporal patterns in stock price movements.

The models used include:

* **Long Short-Term Memory (LSTM) Networks**
* **Simple Recurrent Neural Networks (RNN)**
* **Time Series Forecasting techniques**

These approaches are well-suited for financial data where past trends strongly influence future values.

---

## **Key Highlights**

* Uses **database-driven stock market data**
* Implements **neural networks for sequential data**
* Focuses on **time series prediction**, not regression or classification
* Designed for **financial forecasting and market trend analysis**
* No Streamlit application is included, as the project emphasizes **model development and evaluation**
